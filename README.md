# Sagittarius A* — Milky Way Simulation

An interactive top-down simulation of the Milky Way's spiral structure orbiting
the supermassive black hole at the galactic center (Sagittarius A*), plus a
Sun-centered solar system view with the eight planets orbiting at true
relative periods.

## View it live

Open `index.html` in any browser — no build step, no dependencies.

Once this repo has GitHub Pages enabled (Settings → Pages → Deploy from
branch → `main` → `/ (root)`), it's live at:

`https://thedot-works.github.io/astro-simulation/`

## Controls

- Scroll to zoom, drag to pan the galaxy view
- Play / pause and adjust the rotation rate
- Toggle orbit rings and labels
- Click Sagittarius A* or the Sun for data (mass, orbital period, etc.)
- Open the Solar System panel from the control dock, or from the Sun's info card
